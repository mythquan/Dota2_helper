# Dota 2 新手节奏教练

这个本地程序接收 Dota 2 客户端通过 Game State Integration（GSI）推送的实时数据，使用 OpenRouter、DeepSeek 或 OpenAI 模型生成中文建议，并可选用 Windows 语音。没有模型或请求失败时仍显示实时数据与状态，但不会展示预设的战术建议。原始比赛状态来自 Dota 2，位置判断与建议并非 Valve 官方战术建议。

## 安装与启动（Windows）

1. 安装 Python 3.10 或更新版本。在本目录运行 `python coach.py`；文字版使用 `python coach.py --no-voice`。打开状态页后可选择“核心 / 辅助 / 还不确定”。知道准确位置时，也可在页面“高级”选项中指定，或用 `python coach.py --role 3` 启动。常规提醒默认每 45 秒，可用 `--interval 30` 到 `--interval 120` 调整。
2. 在 Steam 库中打开 **Dota 2 → 管理 → 浏览本地文件**，进入 `game\dota\cfg\gamestate_integration\`。若该目录不存在，创建它。把本目录的 `gamestate_integration_coach.cfg` 复制进去。只复制这个配置文件，不要覆盖已有配置。若使用非默认端口，修改配置中的 URI。
3. 在 Steam 的 Dota 2 启动选项中加入 `-gamestateintegration`，保留你原有的启动参数。安装配置后重启游戏。
4. 打开 <http://127.0.0.1:5000/> 查看连接状态。进入正式比赛后，页面应该显示英雄、时间和建议；PowerShell 窗口也会显示文字。按 Ctrl+C 停止。

**局中提问：**Windows 上按 **Ctrl+F11** 会切到已打开的教练 Chrome 窗口，并聚焦“问教练”输入框。窗口当前选中的标签页需是教练页，标题才能被识别；找不到时不会新开标签页。切换时只改变前台窗口，不改变 Chrome 的最大化状态、尺寸或位置；仅当窗口已最小化时才还原。输入问题后按 **Enter** 发送，**Shift+Enter** 换行；也可点击常用问题按钮直接提问。模型会结合当前可用的 GSI 状态回答；没有比赛数据时会说明缺少实时状态。快捷键由登录用户桌面上的 `hotkey_helper.py` 负责，不修改 Dota 2 按键文件。暂停教练时提问会被拒绝，避免新请求向模型发送数据。已发出的请求仍可能完成并计费。

**模型建议：**可以直接在页面选择 OpenRouter、DeepSeek 或 OpenAI，输入模型 ID 和 API Key，点击“保存模型设置”。密钥只保留在当前服务进程的内存里，重启后需重新输入。也可在启动前设置 `$env:OPENROUTER_API_KEY`、`$env:DEEPSEEK_API_KEY` 或 `$env:OPENAI_API_KEY`；程序会自动选择已配置的服务商，优先 OpenRouter。`--ai-provider off` 可强制离线；`--ai-provider deepseek --ai-model deepseek-flash` 可指定服务商和模型。网页不会回显密钥。

模型每次**建议触发或主动提问**时接收筛选后的 GSI 状态，包括英雄、时间、血蓝、装备、补刀、自己的坐标、队友的小地图英雄名称和坐标、推断区域及与你的直线距离、已在本局观察到的双方英雄名单、当前小地图露头的敌方英雄名称及推断区域、最近两次模型请求间的变化，以及明确标记为推断的分路/位置。敌方阵容记忆只含英雄名称；当前露头区域是近似值，不发送敌方精确坐标、最后露头位置或失踪提醒。不会发送队友账号信息、完整 GSI 包或比赛 ID。常规建议默认约每 45 秒一次，事件触发可能额外调用；不是每个 GSI 推送包都调用。请求失败时页面显示错误状态，不回退到固定战术提示。第三方 API 调用可能产生费用。OpenRouter 和 DeepSeek 接口见各自的 [OpenRouter Chat API](https://openrouter.ai/docs/api/api-reference/chat/create-a-chat-completion) 与 [DeepSeek API 入门](https://api-docs.deepseek.com/guides/search_fetch)；OpenAI 使用 [Responses API](https://developers.openai.com/api/docs/guides/text)。

页面的“暂停教练”只暂停新建议和新模型请求；比赛 GSI 仍继续在本机接收、显示。点击“恢复教练”后，下一包有效游戏数据会立即触发建议。暂停前已经发出的模型请求可能完成并产生 token 用量，但其结果不会覆盖暂停页面。

页面顶部的“游戏状态”可手动标记“新一局开始”或“本局结束”，并填写最多 300 字的本局补充说明。新一局会清除上一局的阵容、问答和手动说明；本局结束会暂停自动建议，下一局的选人/赛前 GSI、不同比赛 ID 或比赛时间回退会自动解除结束标记。补充说明会保存在本机 `manual_context.json`，并在教练启用时随下一次模型建议或主动提问发送，模型会明确知道这是玩家提供的信息；暂停教练时只保存在本机。可随时清空说明。手动标记是玩家反馈，不代表 GSI 已确认对应状态。

页面显示最近一次 API 响应报告的输入、输出、合计 token，以及本次服务启动以来的已报告累计用量。即使模型没有返回可用建议，只要响应带有 `usage`，也会计入；HTTP 错误等未返回用量的请求无法计数。重启服务后计数从零开始，这不是服务商账户的总用量。

本地服务只监听 `127.0.0.1`；启用模型后会向所选 API 发送上述筛选后的状态。后台语音通过 Windows 自带的 System.Speech 合成；如果系统语音不可用，状态页还有“启用网页语音”按钮（需保持页面打开），也可用 `--no-voice` 只看文字。不要在直播中无意展示本机状态页面。

## 数据边界

- 读取 GSI 中的 `map`、`player`、`hero`、`abilities`、`items`、`minimap`。展示时间、英雄、等级、KDA、金币、GPM、血蓝与主物品栏；只有 GSI 明确标记 `ultimate` 的技能才判断大招，缺失值显示“未知”。
- “金钱 / GPM”格子保留当前数值；本局 GPM 曲线显示在整块比赛状态格子的下方。按比赛计时每分钟最多一个点；同一分钟内使用最新收到的 GPM，缺失分钟留空，不推算。下降线段标红，并显示相对上一个采样点的变化。GPM 是从开局至当前的累计平均值，短时下降提示近期收入低于先前平均水平，不能单凭它断定某一分钟的实际收入。采样记录与本局阵容一起保存在本机 `match_memory.json`，换局时清空；服务未运行时无法补记。
- 本地只负责判断何时请求模型：阵亡、复活、血量跌破 35%、蓝量跌破 25%、大招转好、升至 6/12/18 级、获得指定关键物品，以及约每 45 秒触发。除阵亡外，两次请求至少间隔 15 秒；这段时间内触发的状态变化会延后处理。局中战术文字只来自模型，不轮换预设句子。
- 已在练习局实测 `minimap` 返回同队英雄图标和坐标。程序仅使用 `minimap_herocircle` 且队伍匹配的英雄图标，排除自身和普通圆点；由坐标推断队友所在区域。它不能确认队友血蓝、技能冷却、是否愿意支援、路径是否畅通，也不能仅凭位置判断敌方视野或兵线安全。
- 当前练习局还实测 `minimap_enemyicon` 随敌方英雄露头和消失而变化。页面只用这类图标显示当前露头的敌人；某个图标至少连续出现约 3 秒、随后消失约 4 秒才给出一次本地提示，并显示最后露头区域。提示不是敌人真实去向，也可能受视野变化或阵亡影响。当前露头的敌方英雄名称及推断区域会随模型请求发送；敌方图标的精确坐标、历史位置与失踪提醒不发送。
- 本局阵容记忆会累计记录 GSI 曾报告过的己方和敌方英雄，即使敌人后来消失，名单仍保留。它最多保留己方 5 人、敌方 5 人，并显示未识别人数；未曾从 GSI 看到的敌方英雄不会被猜出来。记忆存于本机 `match_memory.json`，包含比赛 ID、阵营、英雄 ID、上次记录时间及逐分钟 GPM；换局清空，服务重启后按比赛 ID 恢复。比赛 ID 只在本地使用，不发给模型。
- 玩家可只选“核心”或“辅助”；分路尚不明确时提供相应的通用建议。分路明确时，按常见组合推断：核心安全路/中路/劣势路通常对应 1/2/3 号位，辅助劣势路/安全路通常对应 4/5 号位。辅助中路等组合不强行推断。`--role` 或页面高级选项是玩家主动指定的位置，优先于推断。物品 ID 列表与建议规则是本项目的判断逻辑，不声称来自官方数据。
- 英雄与物品的简体中文名称直接读取本机 Dota 2 `pak01_dir.vpk` 中的 `resource/localization/abilities_schinese.txt`。游戏更新后重启教练即可重新读取；找不到官方译名时才显示原始 ID。若 Steam 游戏库不在默认位置，可设置环境变量 `DOTA2_GAME_DIR` 为 `game\dota` 目录。
- GSI 的 `hero.xpos/ypos` 是角色当前精确坐标，状态页会原样显示。上中下路、河道、天辉/夜魇半区等中文区域标签是本项目按照当前地图坐标绘制的近似分区，会随着版本地图调整需要复核。坐标能确定位置，但不能单凭位置确定这一局的 1～5 号位或敌方视野。
- 状态页可在对局中选择核心/辅助和本局分路，无需重启服务。英雄名、己方阵营与 `xpos/ypos` 坐标来自 GSI；“当前区域”“开局分路”和位置均为本地推断，会标注来源。开局分路只有在前 7 分钟至少取得 6 次有效位置样本后才判断。中途启动服务而错过前 7 分钟时，可以手动选本局分路。GSI 不提供准确的 1～5 号位字段；有特殊分路、换线或游走时，以玩家实际选择为准。

## 本地验证

运行 `python -m unittest -v` 验证数据解析和触发逻辑。此测试使用模拟的 GSI 形状；还需在真正的 Dota 2 比赛中验证客户端确实向本机推送数据、语音可听见。若页面始终等待，检查配置文件位置、启动选项、游戏是否已重启、5000 端口是否被占用。

## 来源

GSI 配置字段、回环地址与 `provider/map/player/hero/abilities/items` 数据块参考 [ValveSoftware 官方 Dota 2 问题仓库中的 GSI 配置实例](https://github.com/ValveSoftware/Dota-2/issues/1023)。实际客户端字段会随游戏更新变化；程序对缺失字段保留“未知”。
